# 컴퓨터교육·AI교육 리서치 도구

두 개다. 역할이 다르다.

| | 무엇 | 언제 |
|---|---|---|
| `weekly.py` | 주간 메일 브리핑 — **어느 논문을 읽을지 고르는 곳** | 크론, 매주 자동 |
| `eli5.py` | 논문 1편 정독 요약 — **실제로 읽는 곳** | 내가 필요할 때 수동 (로컬 전용) |
| `theories.py` | 이 분야의 **이론 지도** — 한 장으로 보는 곳 | 분기에 한 번쯤 (로컬 전용) |

# 1. 주간 브리핑 (weekly.py)

매주 월요일 08:00 KST에 메일 1통. GitHub Actions가 돌린다.

## 검색 기준 — 최신성이 아니라 정확성

정확하다 = **초등학교 교사가 읽고 수업·생활지도에 옮길 거리가 있다.**
세 조건을 모두 만족해야 한다(`weekly.py` 상단):

| | 무엇을 거르나 |
|---|---|
| `THEMES` | 세 갈래로 나눠 각각 따로 뽑는다 (아래) |
| `LEVEL` | 초등·K-12 (대학·성인 제외) |
| `CONTEXT` | 교실·수업·교사 관점 |
| `EXCLUDE` | 고등교육, 임상·보건 |

갈래를 나눈 이유: 하나의 OR 덩어리로 묶으면 생성형 AI가 relevance를 독점해
나머지가 상위에 한 편도 안 뜬다(실측 — 사이버불링·미디어리터러시를 넣어도 상위 14편에 0편).

| 갈래 | 다루는 것 |
|---|---|
| **수업** | 컴퓨팅사고력, 프로그래밍, AI 리터러시, 교육로봇, **지능형 튜터링·적응형 학습**(AI 디지털교과서가 쓰는 기술) |
| **윤리·정보판별** | AI 윤리, 알고리즘 편향, 디지털 시민성, **미디어 리터러시·허위정보·딥페이크** |
| **웰빙·안전** | 스크린타임, 디지털 과몰입, **사이버불링·온라인 안전** |

`CONTEXT`가 핵심이다. 이게 없으면 같은 "과몰입" 검색이 비만·충치·자세 같은
보건 연구를 상위로 올린다(실측). 교사에게 시사점이 없는 논문이다.

최신순이 아니라 **relevance 정렬로 최근 1년치**에서 고른다. 그러면 매주 같은 상위
논문이 반복되므로, 한 번 보낸 것은 `docs/seen_papers.json`에 기억해 두고 건너뛴다
(최근 300편). 후보가 소진되면 기억을 비우고 처음부터 돈다.

마지막 관문은 요약 단계다. "시사점이 있는가 — 그래서 나는 무엇을 다르게 할 수 있나에
답이 되는가"를 통과하는 것만 싣고, 다섯 편을 억지로 채우지 않는다.

## 어떻게 논문을 고르는가

판별은 **숫자**가 하고, LLM은 **설명만** 한다. LLM에게 순위를 맡기면 매주 기준이
흔들려 주간 비교가 무의미해지고 없는 논문을 지어낸다.

해설은 **Gemini 3.8 Flash**(`generativelanguage.googleapis.com` REST 직접 호출)가 쓴다.
SDK를 안 쓰므로 설치할 패키지가 없다.

| 원하는 것 | 신호 | 계산 |
|---|---|---|
| 최신 트렌드 | 빈도의 **증가율** | 이번 주 토픽 빈도 ÷ (지난 1년 ÷ 52). 절대 빈도는 매주 1등이 같아서 정보가 없다 |
| 이론적 배경 | **공동인용** | 이번 주 신규 논문들이 공통으로 인용한 문헌. 여럿이 동시에 인용 = 그 분야의 공통 전제 |
| 국내 동향 | **Crossref 학회별 DOI 조회** | 한국인공지능교육학회·정보교육학회·컴퓨터교육학회·실과교육연구학회. 초록 없이 제목·저자·DOI |
| 큰 그림 | **리뷰·메타분석 필터** | OpenAlex `type:review`, 최근 30일. 문헌고찰 1편 = 논문 수십~수백 편의 종합 |
| 국내 정책 | **KERIS 동향 리포트** | 월간 「디지털교육 국내외 동향」 최신호 감지 + PDF 링크 |

공동인용은 최신성의 정반대 신호라 상위권이 주마다 안정적이다. 실측에서 Wing(2006)
"Computational thinking"이 1위로 자동 포착됐다.

## 메일에 들어가는 것

- **본문 링크** — 이 분야는 OA(무료 공개) 비율이 ~84%다. PDF 직링크 > OA 랜딩페이지 > DOI
  순으로 걸고, 유료 논문은 `(유료·도서관 프록시 필요)`로 표시한다.
- **ELI5 요약** — 선정 5편은 `쉽게 말하면`(전문용어 0, 초6 수준) + `연구적 의미`(학술 용어 허용)
  두 층으로 나온다. 훑을 때와 각 잡고 읽을 때 쓰임이 다르다.
  근거는 **초록**이다(본문 아님). 초록이 부실한 논문은 ELI5도 부실해진다.

## 셋업

1. 이 폴더를 GitHub 레포로 push
2. Settings → Secrets → Actions 에 4개 등록:
   - `MAIL_TO` — 받을 주소 (보내는 주소로도 쓰임)
   - `GMAIL_APP_PW` — Google 계정 2단계 인증 후 발급한 **앱 비밀번호** (일반 비번 아님)
   - `GEMINI_API_KEY` — https://aistudio.google.com 에서 발급 (무료 티어 있음)
3. Actions 탭 → `weekly-research-brief` → Run workflow 로 1회 수동 테스트

## 아카이브

매주 `docs/YYYY-MM-DD.html`가 저장소에 커밋된다. `git pull` 받아 브라우저로 열면 되고,
거기서 `Ctrl+P` → PDF로 저장.

GitHub Pages는 **켜지 않았다**. 이 저장소는 비공개인데, Pages는 저장소가 비공개여도
사이트를 인터넷에 공개하기 때문이다(접근 제한 Pages는 Enterprise 전용, 무료 플랜은
비공개 저장소에서 Pages 자체가 안 된다). 그래도 쓰고 싶으면 Settings → Pages에서
직접 켠 뒤 `PAGES_URL` 시크릿에 사이트 주소를 넣어라. 그러면 메일 상단에 링크가 붙는다.

## 검색어 바꾸기

`weekly.py` 상단 `TOPIC`(주제)과 `LEVEL`(학교급). OpenAlex 검색 문법이라 `AND`/`OR`/괄호를 쓴다.

실측(2026-09): 43편 중 명백한 오탐 3편(대학 화학교육 등), 확실한 초등·K-12 16편,
나머지 24편은 학교급 불명. `LEVEL`을 조여서 정밀도를 올릴지, 넓게 두고 놓치지 않을지는 취향이다.

## 왜 리뷰 논문을 따로 뽑나

1차 연구(단일 실험, 척도 타당화)만 모으면 브리핑이 지엽적이 된다. EFA·Likert 같은
통계 기법명이 "이번 주 급상승"으로 잡히는 게 그 증상인데, 그건 이 분야의 연구 흐름이
아니라 어느 분야든 설문 논문이면 나오는 공통 어휘일 뿐이다.

체계적 문헌고찰 한 편은 논문 50~200편을 정리한 것이라, **같은 학술 자료인데 층위가 다르다.**
뉴스 기사보다도 정보 밀도가 높다 — "쉬운 트렌드 읽을거리"의 답은 뉴스가 아니라 리뷰다.

30일 창에서는 인용수가 전부 0이라 최신순으로 받고, 약탈적 학술지가 섞이므로
어느 걸 실을지는 요약 단계에서 저널 평판을 보고 고르게 한다.

## KERIS 동향 리포트

월간 「디지털교육 국내외 동향」(통권 224호까지)의 최신호를 감지해 제목과 PDF 링크를 싣는다.
**내용 요약은 하지 않는다** — 40MB짜리 종합 리포트를 한 덩어리로 요약하면 또 뭉뚱그려진다.
정독은 `eli5.py`에 PDF를 넣는 쪽이 낫다.

공개 API도 RSS도 없어서 HTML을 긁는다. 검증된 3단계 체인(인증 불필요):

```
POST selectPblcteOVSEAList.do  ->  <table> 행 + data-id(fileGrpKey)
GET  fileDownChk.do?fileGrpKey ->  JSON {fileKey, 파일명, 크기}
GET  fileDownload.do?fileKey   ->  PDF
```

월간이라 4주 중 3주는 같은 호다. 마지막으로 본 통권 번호를 `docs/keris_seen.json`에
적어두고(워크플로가 `docs/`를 커밋하므로 유지된다) 새 호일 때만 그렇게 표시한다.

HTML 구조에 의존하므로 언제든 깨질 수 있다. 깨져도 브리핑 전체는 정상 발송되고 이 섹션만
빈다 — `stderr` 경고가 Actions 로그에 남는다.

## 국내 논문 — 왜 KCI가 아니라 Crossref인가

KCI OpenAPI 키를 발급받으려면 "신청 IP"(접속 서버 IP)를 등록해야 한다. GitHub Actions
공유 러너는 실행마다 IP가 바뀌므로 이 요구사항과 원천적으로 안 맞는다.

대신 Crossref를 쓴다. 키도 IP 등록도 없고, 목표 학회(한국인공지능교육학회·정보교육학회·
컴퓨터교육학회·실과교육연구학회)가 전부 DOI를 Crossref에 등록해 둬서 커버리지도 된다.
`weekly.py`의 `DOMESTIC_JOURNALS`에서 학회를 추가·삭제할 수 있다(Crossref DOI prefix 기준).

한계 둘:
- **초록이 없다.** 제목·저자·학회·DOI만 온다. "국내 동향" 섹션은 초록 없이 제목만 보고 쓴다.
- **계간지라 발행이 몰린다.** 1주 기준이면 대부분 0건이라, 조회 기간을 30일로 넓혔다
  (`DOMESTIC_WINDOW_DAYS`). 그래도 논문이 2~3주 연속 언급될 수 있다.

# 2. 논문 정독 요약 (eli5.py)

```bash
python eli5.py paper.pdf
python eli5.py https://doi.org/10.1371/journal.pone.0345347
```

`eli5/<이름>.html`로 저장하고 브라우저를 띄운다. 거기서 `Ctrl+P` → PDF로 저장.
`--no-open`을 붙이면 브라우저를 안 띄운다.

PDF 파싱 라이브러리를 쓰지 않는다. Claude API가 PDF를 그대로 받고(표·그림 포함),
웹 주소는 `web_fetch` 서버 툴이 가져온다. 클라이언트 의존성은 `anthropic` 하나뿐이다.

디자인은 `artifact-design` 스킬이 한다. `--allowed-tools`에 `Skill`이 들어 있어야
그 스킬을 부를 수 있다 — 빼면 팔레트도 글꼴도 없는 맨 HTML이 나온다.

섹션은 그림 먼저다: 한 문단 요약 / 무엇이 궁금했나 / 어떻게 알아봤나 / 무엇을 알아냈나 /
초등 현장 시사점 / 한계와 조심할 점 / 연구적 위치(+핵심 인용문헌).
앞 6개는 전문용어 없이, 마지막 1개는 학술 용어 허용.

`claude -p`를 헤드리스로 부르므로 **Claude Code 구독으로 처리된다. API 키가 필요 없다.**
PDF는 Claude Code의 `Read`가(20쪽씩 나눠서), 웹 주소는 `WebFetch`가 읽는다.
읽기 도구 두 개만 허용하고 쓰기 도구는 주지 않는다.

크론에서는 안 돈다 — 로컬 Claude Code가 있어야 한다. 그게 의도다.

# 3. 이론 모음 (theories.py)

```bash
python theories.py            # 아직 없는 이론만 만든다
python theories.py TPACK      # 이름에 이게 들어간 것만 다시
python theories.py --force    # 전부 다시
```

`docs/theories.html`(목차) + `docs/theories/<이론>.html`(이론마다 한 장)로 저장되고
GitHub Pages에 올라간다.

**한 장에 여러 이론을 몰아넣지 않는다.** ELI5는 개념 하나를 그림으로 풀 때 가장 잘
작동한다 — 여섯 개를 한 장에 우겨넣으면 그 강점을 못 쓴다. 그래서 이론마다 독립된
ELI5 한 장을 만들고 목차만 따로 둔다.

어떤 이론을 다룰지는 **데이터가 정한다.** 표본 180편(갈래당 60편)의 참고문헌을 집계해
공통으로 딛고 선 문헌을 찾고(backbone), 그것들이 어떤 이론으로 묶이는지 판별한다.
근거 없는 이론은 만들지 말고 문헌 2편 미만이면 넣지 말라고 못 박았다.

각 페이지: 그림 3~5개 / 한 문장으로 / 무엇을 설명하려는 이론인가 / 어디서 나왔나 /
**초등 교실에서는**(가장 중요한 섹션, "~할 때 ~하게 하라" 수준) / 이 이론으로 연구한다면 /
조심할 점 / 근거 문헌.

실측(2026-09, 29분 35초): 이론 6개 — AI 리터러시, AI4K12 다섯 빅아이디어,
컴퓨팅 사고력, 만들면서 배우는 기계학습, 교사 공동설계, K-12 AI 교수설계.
장당 SVG 4개.

**크론에는 안 올라간다.** eli5.py와 마찬가지로 로컬 Claude Code 구독을 쓰는데,
GitHub Actions 러너에는 `claude` CLI가 없다. 분기에 한 번쯤 손으로 돌린다.
